Muuzika 3.1.0-beta3 - Windows x64
Vibe-coded by kris

START
Extract the entire ZIP and run Muuzika-Windows/Muuzika.exe.
Python is not required. Keep _internal beside the executable.
Close an older copy before starting the new version.

NEW IN BETA2
Default window size: 400 x 500. Saved custom sizes are preserved.
Minimum size: 360 x 440. Settings > Window > Adjust window size unlocks
resizing temporarily. Save size commits; Cancel restores.
Retro MENU is on the wheel. Other pages have a Back arrow; Escape returns to the previous view.
Original style has one balanced control row. The header has a magnifier in its
search field: type and press Enter. Outside click clears and unfocuses it.
Add files and cloud sync are at the top right; no bottom toolbar remains.
Time, volume and hints have larger typography.

PALETTES
Settings > Style > Choose a color palette opens visual previews.
Click a card to preview its colors. Save applies; Cancel discards the preview.
Edit every color opens HEX/RGB editing. To keep your current colors as a
reusable preset, open the gallery, enter a unique name and press Save as.
Named palettes are saved immediately and remain available after restart.
Layouts (Original/Retro) and colors can be chosen separately.

PLAY
Click a track to play. Ctrl/Shift selects multiple rows; dragging reorders.
Retro: center plays/pauses, sides skip, bottom stops, top MENU navigates.
Volume wheel snaps to 5-percent boundaries. Routine downloads are silent.

DATA AND NEXTCLOUD
No music, passwords or personal server configuration are in this ZIP.
Data is stored in %APPDATA%\Muuzika GPT-BETA, shared with the source version.
Library search uses the local snapshot. Server sync refreshes it on request.
Uncached remote audio downloads when played; Test connection is explicit.
Automatic sync, prefetch and listening reports are disabled.

TESTING AND NOTICES
Tested with isolated synthetic metadata, silent audio and blocked networking.
No live Nextcloud server or clean Windows VM was tested. This beta is unsigned.

Pre-release review update:
Navigation now uses an integrated full-page menu with labeled icons.
Settings, color editing and the palette gallery hide header actions and the
playback panel while audio continues. Back and Escape return to the player.
Decorative color strips have been removed from every preset.
All built-in foreground/background text pairs are checked for contrast.
Custom user colors remain under user control and can reduce readability.
